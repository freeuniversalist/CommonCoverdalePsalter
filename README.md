# The Common Coverdale Psalter

A freely licensed psalter in the Coverdale tradition, encoded for
liturgical use, in two parallel versions:

- **bcp1928** — the Psalter of the 1928 American Book of Common Prayer:
  Miles Coverdale's 1535 translation as revised through the American
  prayer books of 1789, 1892, and 1928. 
- **modern** — The Common Coverdale, a modernization of the 1928 text
  made for this project: pronouns and verb forms updated, archaisms
  cleared, and a small number of renderings corrected toward the Hebrew.

## Contents

    psalter.xsd        XML Schema defining a simple ad hoc format
    psalter.xml        the psalter (both versions, with apparatus)
    renderToHTML.py    renders the XML to a plain HTML psalter
